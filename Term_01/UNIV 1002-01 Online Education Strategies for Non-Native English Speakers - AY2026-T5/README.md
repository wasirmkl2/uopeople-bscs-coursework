## About this course

Strategies and skills for succeeding in an online, English-medium academic environment,
aimed at non-native English speakers, as part of the BS-CS program at the University of
the People.

## Folder structure

Work for this course is organized by content type:

| Folder | Contents |
|---|---|
| `Readings/` | Unit reading assignments (provided course material). To be added as the term progresses. |
| `Assignments/` | Written assignments submitted for grading. |
| `Discussions/` | Discussion board initial posts and peer replies. |
| `Exams/` | MCQ / True-False exam material and notes. |

Within each folder, group files by unit as the term progresses (e.g., a `Unit N/`
subfolder, or a `Unit N -` file-naming prefix) so all of a given unit's work is easy to
find together.
