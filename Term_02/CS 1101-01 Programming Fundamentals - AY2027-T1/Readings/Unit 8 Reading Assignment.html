Unit 8 Reading Assignment

As you go through the readings and watch the video, consider the following:

  1. What is a module in Python, and how does it help organize and reuse code efficiently?
  2. What is Object-Oriented Programming (OOP), and how does it differ from procedural programming?
  3. What are classes and objects, and how do they help organize code in Python?
  4. How do Python’s modules and OOP features complement each other in building large, reusable programs?

Read:

  1. Mohbey, K. K., & Acharya, M. (2023). Basics of Python programming: A quick guide for beginners. Bentham Science Publishers.

    • Read Chapter: Modules and Packages
      • Section - Modules
        This section explains how Python organizes and reuses code through modules. It introduces the concept of importing modules and demonstrates different ways to access their contents using statements like import and from…import. Learners explore how to rename modules for convenience, use the dir() function to inspect available attributes, and apply the reload() function to refresh a module after changes. The section also highlights Python’s wide range of built-in modules, showing how they simplify programming tasks by providing ready-to-use functions and tools.
    • Read Chapter: Object-Oriented Programming
      This chapter provides an overview of Object-Oriented Programming (OOP) and its core concepts as implemented in Python. It begins by introducing classes and objects as the foundation of OOP, emphasizing how they help structure programs around reusable components. The section then explores key principles such as data abstraction, which hides complex implementation details; encapsulation, which safeguards data by combining it with the methods that operate on it; and inheritance, which allows new classes to derive properties and behaviors from existing ones. It also discusses polymorphism, where the same interface can perform different actions depending on the object it is applied to, and explains the role of constructors in initializing object attributes. Overall, the section highlights how OOP in Python enhances code organization, reusability, and scalability.

  2. Mastrodomenico, R. (2022). The Python book. John Wiley & Sons, Incorporated.

    • Read Chapter 3: Packages and Builtin functions
      The chapter begins by describing how packages group related modules to make large programs easier to manage and maintain. It covers how to create, install, and import packages using Python’s package manager, pip, and the import statement. The chapter also explores the structure of Python’s standard library, highlighting common modules such as math, os, sys, and datetime that extend Python’s capabilities without additional installation. Additionally, it provides an overview of built-in functions—predefined tools like len(), type(), range(), print(), and input()—that simplify everyday programming tasks. Overall, this chapter emphasizes how leveraging packages and built-in functions helps programmers write cleaner, more efficient, and modular Python code.
