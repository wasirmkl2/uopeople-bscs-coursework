Read:

  1. Mohbey, K. K., & Acharya, M. (2023). Basics of Python programming: A quick guide for beginners. Bentham Science Publishers.

    • Read Chapter: Sequence-String and List
      • Section - String
        This section provides a comprehensive overview of string operations and manipulation in Python. It explains how strings can be created, combined, and modified using various techniques such as concatenation, appending, and multiplication. The section also introduces string formatting methods, including the use of operators, functions, and formatting classes.
        Learners are introduced to built-in string functions for slicing, comparison, and iteration, along with key functions like ord() and chr() for character encoding and decoding. The subsection further explores the string module, detailing its constants (such as ascii_letters, digits, and punctuation) and classes (Formatter and Template) that aid in advanced text processing. Finally, it covers regular expressions, emphasizing their use in pattern matching and text analysis.
    • Read Chapter: File Handling
      This chapter provides a detailed explanation of file handling and directory operations in Python. It covers the full range of file-related tasks, including opening, closing, reading, and writing files, as well as using different methods such as write(), writelines(), read(), readline(), and readlines(). It also explains how to create new files, examine file object attributes, and manage file positions. Beyond basic file handling, the section explores advanced file operations, such as renaming and deleting files, and introduces binary file handling for non-text data. It also includes a comprehensive overview of directory operations, explaining how to view the current working directory, list contents, create and rename directories, change directories, and delete them.
    • Read Chapter: Exception Handling
      This chapter focuses on exception handling in Python, explaining how errors can be detected, managed, and prevented during program execution. It introduces the concept of exceptions and demonstrates how to use try–except blocks to handle runtime errors gracefully without interrupting program flow.
      The chapter further explains the roles of the else and finally keywords for executing additional code after exception handling or performing necessary cleanup actions. Learners also explore how to raise custom exceptions intentionally using the raise statement to enforce specific conditions or constraints within a program.
