Unit 3 Reading Assignment

As you go through the readings and watch the videos, consider the following:

  1. What are the key differences between for loops and while loops in Python?
  2. How does a for loop iterate over sequences such as lists, strings, or ranges?
  3. What are break and continue statements, and how do they alter the normal flow of a loop?
  4. What is a nested loop, and how does it differ from a single loop?

Read:

  1. Mohbey, K. K., & Acharya, M. (2023). Basics of Python programming: A quick guide for beginners. Bentham Science Publishers. (Access through LIRN)

    • Read Chapter: Looping Statements
      This chapter focuses on programming structures that allow the repeated execution of a set of instructions. It begins with the for loop, which iterates over sequences such as lists or strings, and the while loop, which continues running as long as a specified condition remains true. The chapter then explores nested loops, where one loop operates inside another to handle more complex tasks. Additionally, it introduces control statements like break, continue, and pass, which modify the normal flow of loops — allowing early termination, skipping specific iterations, or serving as placeholders in code.

  2. Alex The Analyst. (2022, November 29). While loops in Python | Python for beginners [Video]. YouTube. https://www.youtube.com/watch?v=ECduJk00mUU

    This video guides beginners through the concept of the while loop in Python, showing how it repeatedly executes a block of code as long as a given condition remains true. He explains the basic syntax, walks through practical examples of how to use it in real-code scenarios, highlights the risks of infinite loops, and demonstrates how the loop’s termination condition governs when the iteration stops. The tutorial is concise, accessible, and designed for new programmers who want to build a solid foundation in loop control structures in Python.

  3. Khan Academy. (2024, July 24). break and continue | Intro to CS - Python | Khan Academy [Video]. YouTube. https://www.youtube.com/watch?v=Xnzjr0Pcx-A

    This video introduces the loop-control statements break and continue in Python. The video explains how a break statement can be used to exit a loop immediately when a specific condition is met, halting further iterations, while a continue statement skips the remainder of the current loop iteration and proceeds with the next one. It also discusses practical scenarios—such as handling invalid or special-case data—where skipping work (via continue) or terminating early (via break) leads to cleaner, more readable logic rather than deeply nested conditions.
