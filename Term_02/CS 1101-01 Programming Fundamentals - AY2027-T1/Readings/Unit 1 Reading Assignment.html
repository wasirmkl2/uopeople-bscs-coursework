Unit 1 Reading Assignment

As you go through the readings and watch the videos, consider the following:

  1. What problem does each concept (type, operator, expression) help solve in real programs?
  2. Where does Python excel and where might another language be a better fit?
  3. Which operations are valid for each basic type (int, float, str, bool, set, dict, list/tuple)?

Read:

  1. Mohbey, K. K., & Acharya, M. (2023).  Basics of Python programming: A quick guide for beginners. Bentham Science Publishers. (Access through LIRN)

    • Read Chapter: Introduction to Python
      This chapter provides a high-level overview of Python and its role in modern computing, outlining the language’s design philosophy and common use cases. It explains Python’s technical strengths—readable syntax, dynamic typing, multi-paradigm support, a rich standard library and package ecosystem, cross-platform portability, and easy interoperability with other languages. Brief comparisons to other languages help clarify where Python excels (e.g., data analysis, web development, scripting/automation, and education), setting expectations for how and when to use it in later chapters.
    • Read Chapter: Data Types, Operators, and Expressions
      • Section — Introduction
      • Section — Number
      • Section — Dictionary
      • Section — Boolean
      • Section — Set
      • Section — Type Conversion
      These sections cover Python’s core building blocks: fundamental data types (numbers, sequences, dictionaries, Booleans, and sets) and how to convert between them (implicit and explicit type conversion). It explains the full range of operators—arithmetic, relational, assignment, unary, bitwise, logical, membership, and identity—along with precedence and associativity, then shows how identifiers and literals combine into valid expressions. It concludes with essential string operations.

Watch:

  1. TeachingCS. (2022, July 31). Python for beginners - Inputs & outputs explained [Video]. YouTube. https://www.youtube.com/watch?v=kvKvYXXuHoo

    The video introduces beginners to how Python handles input and output operations. It explains how to use the input() function to receive user data, the print() function to display results, and demonstrates converting input values to different data types. The video provides clear, practical examples to help new programmers understand how user interaction works in Python.

  2. TeachingCS. (2022, July 31). Python for beginners - Variables explained [Video]. YouTube. https://www.youtube.com/watch?v=SBghUPOWd4w

    The video introduces the concept of variables in Python. It explains what variables are, how to create and assign values to them, and the rules for naming variables. The video also demonstrates different data types and shows how variables are used to store and manipulate data in Python programs.
