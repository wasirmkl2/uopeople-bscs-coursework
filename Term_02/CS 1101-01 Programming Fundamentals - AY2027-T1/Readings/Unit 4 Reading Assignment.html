Unit 4 Reading Assignment

As you go through the readings and watch the video, consider the following:

  1. What is the difference between a predefined (built-in) function and a user-defined function in Python?
  2. How do parameters and arguments differ, and why are both important when calling a function?
  3. How do local and global variables behave differently in Python, and what are the advantages or risks of using each?
  4. How can shadowing cause unintended behavior or logical errors in a program?

Read:

  1. Mohbey, K. K., & Acharya, M. (2023). Basics of Python programming: A quick guide for beginners. Bentham Science Publishers. (Access through LIRN)

    • Read Chapter: Functions
      This chapter explains how functions are used to organize and reuse code in Python programs. It begins by defining functions and distinguishing between predefined and user-defined ones, then describes how to call functions, pass arguments, and work with default values. The chapter explores the concept of variable scope and lifetime, clarifying the differences between local and global variables and explaining how variable visibility affects program behavior. It also introduces the return statement for sending values back from functions, as well as lambda (anonymous) functions for writing compact, one-line operations. Finally, the chapter discusses recursive functions and how functions can be redefined, emphasizing how these concepts contribute to efficient, modular, and maintainable programming.

  2. Bencini, N. (2025, March 4). Variable shadowing in Python. Medium. https://medium.com/@nicbencini/variable-shadowing-in-python-cfc5457a67c3

    This article discusses how variable shadowing occurs when a local variable inside a function or inner scope uses the same name as a variable in an outer scope. It explains how this can lead to confusion and bugs, particularly in Python’s scoping rules. The post gives examples of shadowing in functions, loops, and nested scopes, and it outlines best practices for avoiding such issues—such as using clear variable names, understanding scope boundaries, and resisting inadvertent reuse of outer-scope variables.

Watch:

  1. Programming with Mosh. (2018, November 6). Python functions | Python tutorial for absolute beginners #1 [Video]. YouTube. https://www.youtube.com/watch?v=u-OmVr_fT4s

    This video introduces the fundamental concept of functions in Python. It explains how to define and call functions, pass arguments (including default values), and return values. The video also covers variable scope—local versus global—along with a demonstration of lambda (anonymous) functions and a quick look at built-in functions, all aimed at helping beginner programmers write cleaner, more modular code.

  2. w3schools.com. (2024, July 15). Python - global variables - W3Schools.com [Video]. YouTube. https://www.youtube.com/watch?v=VZW9CGZymqU

    This video explains how global variables work in Python and how they differ from local variables. It demonstrates how variables defined outside a function can be accessed and modified within functions using the global keyword. The video also covers best practices for using global variables, including when to avoid them to prevent unexpected behavior and how to maintain clean, readable code. Through simple examples, it shows how variable scope affects program logic and emphasizes understanding global vs. local contexts to write more efficient Python programs.

  3. Bro Code. (2024, July 14). Learn Python LAMBDA in 6 minutes! [Video]. YouTube. https://www.youtube.com/watch?v=IljPHDyBRog

    This video explains how to use Python’s lambda functions—anonymous, one-line functions defined using the lambda keyword. It covers what lambda functions are, how to write them (e.g., double = lambda x: x * 2), and when they are useful—such as for simple operations, passing as arguments to functions like map(), filter(), or sorted(). The video also shows example usages: defining one-line lambdas with one or more arguments, returning a value directly, and highlights that they’re suited for quick, throwaway functionality rather than large multi-statement logic (which is better handled by standard def functions).

  4. mCoding. (2024, June 4). All 71 built-in Python functions [Video]. YouTube. https://www.youtube.com/watch?v=7Qu_KXc7xSI

    This video gives a concise overview of every built-in function included in Python. The presenter briefly explains and demonstrates how each function works, covering categories such as type conversion (int(), float()), data handling (len(), sum(), max()), iteration and mapping (map(), filter(), zip()), and object inspection (type(), dir(), getattr()). The video emphasizes how these built-ins simplify programming tasks, reduce redundancy, and improve code readability without requiring external libraries
