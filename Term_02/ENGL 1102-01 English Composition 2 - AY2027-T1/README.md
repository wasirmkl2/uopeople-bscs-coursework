## Folder structure

Work for this course is organized by content type:

| Folder | Contents |
|---|---|
| `Readings/` | Unit reading assignments (provided course material). |
| `Assignments/` | Written assignments submitted for grading. |
| `Discussions/` | Discussion board initial posts and peer replies. |
| `Exams/` | MCQ / True-False exam material and notes. |

Within `Assignments/`, `Discussions/`, and `Exams/`, group files by unit as the term
progresses (e.g., a `Unit N/` subfolder, or a `Unit N -` file-naming prefix) so all of a
given unit's work is easy to find together.

## Discussion deadlines

Unless a specific unit's instructions say otherwise:

- **Main/initial discussion post:** due Sunday.
- **Peer replies:** due Wednesday.
